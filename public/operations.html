현재 배포의 회귀 확인 계획입니다. 공식 41종 시험 목록이 아니며, 실제 API 응답·요청 ID·확인 시각과 가린 서버 기록이 모두 맞는 결과만 실측으로 남깁니다. 현재 이 표의 실측 기록 연결은 준비 전입니다.

실측 기록 절차
  1. 동일한 배포 주소·커밋을 고정하고 정상 요청과 금지 요청을 각각 실행합니다. 엔진 경유 시험과 직접 API 시험을 구분합니다.
  2. 각 실제 응답의 HTTP 상태·판정·자료 비노출/대상 일치 여부를 확인합니다. 메모 제목·본문·토큰은 기록하지 않습니다.
  3. 응답 또는 엔진의 요청 ID와 UTC 확인 시각을 남기고, 같은 요청의 가린 서버 기록과 대조합니다. ID를 받지 못하면 ‘요청 ID 없음·대조 미완료’로 남깁니다.
  4. 정상 허용과 금지 거부가 모두 실측·대조되어야 해당 단계의 확인 완료로 기록합니다. 실패·미실행·연동 불가를 통과로 바꾸지 않습니다.

복원·회수는 지정한 학습 대상과 사본을 확인한 뒤 수동 진행합니다. 이 화면은 시험이나 복원을 자동 실행하지 않습니다.
